# Images to generate

Every image the console uses. Save each file in your repo at **/img/console/** with the exact filename below. Until a file exists, the console falls back to the photo already in your app's /img/ folder (right column), so nothing breaks while you generate them.

## Style guide for every image

- Photoreal, Sabah only, natural light. Navy (#061A47), royal blue (#004AAD) and cyan (#5DE0E6) should sit comfortably in the palette; avoid neon or heavy filters.
- No text, no logos, no watermarks, no flags, no legible signage.
- No identifiable faces of real people; any people shown are fictional and seen at a distance or from behind, except the fictional merchant portrait.
- Leave calm space where text sits: left third for hero images, bottom third for portal cards.
- Export JPG at 80% quality (PNG only for Bella). Keep each file under 400 KB.

Suggested prompt suffix: *"photorealistic, Sabah Borneo, natural light, deep navy and teal colour grade, no text, no logos, 35mm, high detail"*
